## 1. 🕐 Basic Clock Concepts

A clock has two main hands:

- **Hour Hand**
- **Minute Hand**

A clock dial contains:

```
12 numbers
60 minute divisions
360° total
```
---
## 2. 📐 Clock Dial
```
The complete clock circle is:

360°

There are 12 equal divisions between the numbers.

Therefore:

360° ÷ 12 = 30°

So, the angle between two consecutive numbers is:

30°

Important
1 hour = 30°

For example:

12 → 1 = 30°
1  → 2 = 30°
2  → 3 = 30°
...
11 → 12 = 30°
```
---

## 3. ⏱️ Movement of Clock Hands
```
Minute Hand

The minute hand completes:

360° in 60 minutes

Therefore:

360° ÷ 60 = 6°

So:

Minute Hand = 6° per minute

Hour Hand

The hour hand completes:

360° in 12 hours

Therefore:

360° ÷ 12 = 30°

So:

Hour Hand = 30° per hour

But the hour hand also moves continuously with the minutes.

Therefore, in 60 minutes:

Hour hand moves = 30°

So:

1 minute = 30° ÷ 60
         = 0.5°

Therefore:

Hour Hand = 0.5° per minute
```
---
## 4. ⚡ Relative Speed
```
The minute hand moves faster than the hour hand.

Minute Hand = 6°/minute
Hour Hand   = 0.5°/minute

Therefore:

Relative Speed
= 6 - 0.5
= 5.5°/minute

So:

Relative Speed of the two hands = 5.5° per minute

or

11/2° per minute
Important Rule

When both hands move in the same direction:

Relative Speed = Difference of Speeds
```
---
## 5. 📌 Basic Angle Formula
```
At a time of:

H hours M minutes

the positions of the hands can be calculated using their movement.

Minute Hand
Minute Hand Angle = 6M
Hour Hand
Hour Hand Angle = 30H + 0.5M

Therefore, the angle between the hands is:

Angle = |30H - 5.5M|

The smaller angle is:

Smaller Angle = min(Angle, 360 - Angle)
```
---
## 6. 🧮 Example — Finding the Angle
```
Example

Find the angle between the hands at:

3:15
Minute Hand
6 × 15
= 90°
Hour Hand
30 × 3 + 0.5 × 15
= 90 + 7.5
= 97.5°
Difference
97.5 - 90
= 7.5°

Therefore:

Angle = 7.5°
```
---
## 7. 🔄 Reflex Angle
```
There are two angles between the hands of a clock.

If one angle is:

θ

then the other angle is:

360° - θ
Example

If one angle is:

217.5°

then the smaller/reflex corresponding angle is:

360° - 217.5°
= 142.5°

Therefore:

Smaller Angle = 142.5°
```
---
## 8. 🎯 Finding the Time for a Given Angle
```
For a given hour, we can use the relative movement of the hands.

Since the relative speed is:

5.5° per minute

the time required for a relative movement of D° is:

Time = D / 5.5 minutes

or:

Time = 2D / 11 minutes

This is useful when solving questions involving a particular angle.
```

## 10. ⭕ Coinciding Hands
```
When the hour hand and minute hand are at the same position, they coincide.

Therefore:

Angle = 0°

The hands coincide approximately every:

65 5/11 minutes

or:

65.45 minutes

within each 12-hour cycle.

📌 Important Observation

The hands do not coincide exactly once every hour.

Because the hour hand continues moving while the minute hand completes each revolution.
```
---
## 11. 🔁 Number of Coincidences
```
In approximately:

12 hours → 11 coincidences
24 hours → 22 coincidences

This is an important pattern for exam questions.
```
---
## 12. ⏺️ Opposite Hands
```
When the hour hand and minute hand are exactly opposite:

Angle = 180°

The hands form a straight line.

They occur approximately:

11 times in 12 hours
22 times in 24 hours
```

## 14. 🧠 Important Counting Rule
```
When a question asks how many times the hands make a particular angle, always check:

Starting Time
Ending Time
Whether the endpoints are included
Whether the occurrence happens exactly at an endpoint

This is especially important for:

0° → Coinciding
180° → Opposite
```

## 15. 🕰️ Clock Gains or Loses Time
```
A clock may:

Gain time
Lose time
Gain

If a clock gains:

x minutes

then the clock shows a time ahead of the actual time.

Lose

If a clock loses:

x minutes

then the clock shows a time behind the actual time.
```
---
## 16. 📈 Fast Clock
```
A fast clock gains time compared with the correct clock.

General Approach

If a clock gains:

g minutes in t hours

then calculate the gain proportionally for the required period.

For example:

Gain per hour
= Given Gain / Given Hours

Then calculate the total gain for the required time.
```
---
## 17. 📉 Slow Clock
```
A slow clock loses time compared with the correct clock.

General Approach

If a clock loses:

l minutes in t hours

then:

Loss per hour
= Given Loss / Given Hours

Then calculate the total loss for the required period.
```

## 19. 🪞 Mirror Clock
```
A mirror clock question asks for the time shown in a mirror.

For a 12-hour clock, the standard relationship is:

Mirror Time = 11:60 - Given Time
Example

If the actual time is:

3:00

then:

11:60
- 3:00
------
 8:60

which gives:

9:00

Therefore:

Mirror time = 9:00
```
---
## 20. 🪞 Mirror Clock Examples
```
Example 1

Given:

3:00

Mirror:

9:00
Example 2

Given:

7:20

Use:

11:60 - 7:20
= 4:40

Therefore:

Mirror time = 4:40

Important Formula
12-hour Mirror Time
= 11:60 - Given Time
```
---
## 21. 🕐 24-Hour Clock Conversion
```
To convert a 24-hour time into a 12-hour format:

For PM Times

Subtract:

12

from the hour.

Examples
20:00 → 20 - 12 = 8:00 PM

22:15 → 22 - 12 = 10:15 PM

13:00 → 13 - 12 = 1:00 PM
📌 Important

For:

12:00 → 12:00 PM
00:00 → 12:00 AM
```
