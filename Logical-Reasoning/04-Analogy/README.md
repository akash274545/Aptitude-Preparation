## 🧠 Types of Questions

### 1. Find One Word

```text
Farmer : Field :: Artist : ?
```

Answer: **Theatre**

### 2. Find Pair

The blank may be on either the left or right side.

### 3. Statement Based

Identify the relationship between the first pair and apply the same relationship to the second pair.

```text
Speedometer : Speed :: Compass : ?
```

Answer: **Direction**

### 4. Alternate Word

```text
Boat : House :: ?
```

Identify the relationship first and apply the same relationship.
