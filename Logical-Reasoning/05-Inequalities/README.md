## 🧠 Meaning of Inequality

**Inequality** means comparison.

For comparison, the quantities or variables must use the same unit.

### Examples

```text
Weight(1) — Weight(2)
Height(1) — Height(2)
```

---

## 🔣 Basic Symbols

| Symbol | Meaning |
|---|---|
| `>` | Greater than |
| `<` | Less than |
| `=` | Equal to |
| `≥` | Greater than or equal to |
| `≤` | Less than or equal to |

### Composite Symbols

```text
> + =  →  ≥
< + =  →  ≤
```

## 🔗 Basic Rules

### Relationship Between Variables

There should be a relationship between the variables.

If there is **no valid relationship**, the conclusion cannot be established.

### Example

```text
P > Q > R < S < T
```

From this chain:

- `P > R` → True
- `R > P` → False
- `P > T` → False
- `T > S` → True

---

## ➡️ Chain Method

The chain method is used to compare variables connected through a continuous relationship.

### Example

```text
A > B > C < D < E
```

From the chain:

- `A > C` → True
- `C > A` → False
- `D > C` → True
- `D < E` → True

A conclusion is valid only when the required variables are connected through a proper chain.

---

## 🚪 Gate Method

The gate method is used when the direction of inequality changes.

When a chain changes direction, carefully check whether the required comparison can be established.

```text
L < < < < < R
```

The direction and connection between variables must be checked before selecting an answer.

---

## ➕ At Least One Rule

For a chain containing `>` or `<`, the relationship may be established through the connected inequalities.

### Example

```text
A > B > C
```

Therefore:

```text
A > C
C < A
```

are true.

---

## 🔁 Continuous Relationship

A continuous relationship is required when the comparison depends on every connected symbol in the chain.

### Example

```text
P ≥ Q ≥ R
```

- `P ≥ R` → True
- `P > R` → Not necessarily true
- `R < P` → True

---

## ⚖️ Equality Relationships

The equality symbol allows the comparison to work in both directions.

### Example

```text
A = B
```

Therefore:

```text
A ≥ B
A ≤ B
B ≥ A
B ≤ A
```

The equality symbol can connect the left and right sides of a chain.

---

## 📌 Important Notes

### Strict Inequality

```text
A > B
```

A is definitely greater than B.

### Non-Strict Inequality

```text
A ≥ B
```

A is either greater than or equal to B.

### Reverse Direction

```text
A > B
```

can also be written as:

```text
B < A
```

### No Direct Relation

If two variables are not connected by a valid chain, their comparison cannot be concluded.

## 📝 Practice Examples

### Example 1

```text
A > B > C = D
```

- `A > C` → True
- `C > A` → False
- `B = C` → False
- `C = D` → True
- `A > D` → True

### Example 2

```text
P ≥ Q ≥ R ≥ S > T
```

- `P > R` → Not necessarily true
- `P ≥ S` → True
- `R > T` → True
- `T > P` → False

### Example 3

```text
A ≥ B = C > D ≤ E = F
```

- `A > C` → Not necessarily true
- `A ≥ C` → True
- `B > D` → True
- `B > E` → Cannot be concluded
- `E = F` → True

## 🎯 Statement and Conclusion Questions

These questions provide a statement containing relationships between variables, followed by two conclusions.

The task is to identify which conclusion or conclusions follow.

### Answer Options

```text
A. Only conclusion I follows
B. Only conclusion II follows
C. Either conclusion I or II follows
D. Neither conclusion I nor II follows
E. Both conclusion I and II follow
```

### Solving Method

```text
Read the statement
        ↓
Identify the connected variables
        ↓
Draw or arrange the chain
        ↓
Check Conclusion I
        ↓
Check Conclusion II
        ↓
Select the correct option
```
