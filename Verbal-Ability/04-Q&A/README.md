## 🧠 How to Learn Vocabulary

The study method recorded in the notes:

1. Learn the basic **2000 words**
2. Use the words in daily language
   - Marathi / Hindi sentence practice
3. Monday–Friday — Vocabulary
4. **5 Times Hammer** — repeated revision
5. Saturday — **100-word revision**

### Example Vocabulary

```text
Apathy    → Lack of interest
Sympathy  → Feeling of pity
Empathy   → Understanding another person's feelings
Antipathy → Strong dislike
```
